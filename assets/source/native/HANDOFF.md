# 给 Claude 的交接

本包包含19张透明PNG：2张造型、17张动作，共107个动作帧。仅提供美术资源；未修改游戏目录或仓库，未做游戏内导入验收。

## 已做检查

- 两张造型：1024×1024，角色34逻辑像素高，脚底到逻辑y=100。
- 全部PNG：每一逻辑像素为严格对齐的8×8纯色块，无半透明边、抗锯齿或抖色。
- 调色板按英雄统一，拉克丝最多19色，艾希最多18色。
- 动作格尺寸448×512，按附包指定的列数、行数和帧序。7帧动作的最后一格透明。
- 逐张查看动作序列；用验收后的头部像素修正生图中变窄的脸，受击首帧闭眼；死亡姿态保留生成的转头/倒地形态；拉克丝R第7帧按提示允许遮脸。
- 拉克丝造型杖杆及R悬浮杖校直，补齐艾希武器的小断线，清除游离暗点。

## 导入

直接逐8×8块取样，还原逻辑像素；不要再做平滑缩小或二次降色。每帧逻辑画布56×64。沿用现有动作命名、帧时长与事件。MANIFEST.json中有各帧参考轮廓框、放置位置和文件SHA256。

这是按参考帧放置后目视检查的美术交付，不等于游戏内像素级重合或战斗效果验证。请按现有导入工具继续核对头部轨迹、前冲、R杖高度、死亡腾空/落地及HUD/卡片显示，运行项目的lint和游戏内检查。

preview.html可离线逐帧/播放预览，预览速度可调，未替代游戏的帧时长。
