## 导入说明

- 所有原图都是单行从左到右排列的 RGBA PNG，具有真实 alpha 通道。原图保留生成器输出，没有裁切、重绘或缩放。
- **生成器的实际画幅为 2172×724，带额外留白，不是已经规格化的游戏帧格。不要用整张图片高度推算方格宽度。** 按指定帧数等分宽度，先取全高，再统一裁去留白、补齐帧格。5、7、8 帧图不能整除宽度，分界可用 `round(i * width / frame_count)`；每个候选矩形已写在 `manifest.json`。
- `manifest.json` 记录原图尺寸、SHA-256、透明/半透明像素数，以及每帧的候选源矩形和 alpha≥128 包围盒。矩形是切帧起点，最终仍须目检粒子归属；不要逐帧紧裁后直接拼接，否则会丢失锚点关系。
- 按最初分工，由 Claude 完成：缩到游戏尺寸、硬边像素化、去除半透明、统一金色色阶、对齐锚点、生成游戏动画资源、绑定现有技能。普通特效目标帧格为正方形；圣剑为宽高 1:2，固定落地点。盾牌以盾体定位，不能按变化中的火焰包围盒重新居中。
- 原图包含半透明边缘，尤其低亮度尾帧；处理透明度时先保留淡色火花，再量化为硬边。循环图的末帧到首帧衔接、帧时长和游戏内效果需要在接入时验证。

如导入工具仍读取 `D:\hok_fx\`，在仓库根目录执行：

```powershell
New-Item -ItemType Directory -Force -Path D:\hok_fx | Out-Null
Copy-Item -Path .\assets\source\arthur_fx\*.png -Destination D:\hok_fx
```

本次交付也将原图复制到该本机路径。仓库内的原图应保留，以便重做导入。
