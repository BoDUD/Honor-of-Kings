# 艾希生图交接

本包交付 16 张 GPT Image 生成的 PNG 原始素材：1 张统一造型参考、9 张角色动作、6 张独立特效。对应 TFM2-League-Heroes PR #4。用户授权范围是生成图片并由用户交给 Claude 收尾；本次未修改仓库或运行游戏导入。

## 已完成

- 按原压缩包 PROMPTS.md 分别生图，每个文件是一行帧序列，文件名与原文对应。
- 先生成 ashe_ref.png；所有角色动作均使用这张造型参考，另附对应 Riot 姿势参考（hit 除外）。
- 检查角色身份、朝向、持弓侧、动作数量和透明通道。对待机、跑步、普攻、Q 连射、Q 发动、W、R 和 R 命中进行了一轮针对性重生成；未混用另一张造型参考。
- 内置工具返回 HTTP 404 后，使用本机 gpt-image-bridge，经 Codex CLI 的原生 GPT Image 能力生成。没有使用程序绘画代替生图，也没有进行最终切帧或像素修整。

## 收尾时注意

这些是供切帧、修整的生成源图，不是已通过游戏验收的精灵图集。生成器没有严格遵守指定画布大小、正方形格子和统一角色像素身高；实际尺寸见 manifest.json。请按可见帧内容切取，再对齐角色身体尺度与脚底，不要直接把整张图缩到游戏尺寸，也不要假设 width/N 的边界能直接无损切帧。

- 各张图均含真实 alpha，但存在半透明边缘及低 alpha 杂点。角色应清理杂点并做硬边 alpha；特效按需要保留透明衰减。
- 生图保留了像素画风，但颜色数与像素网格并非严格受控。按原计划缩到约 34 px 身高，统一调色板、修补 1 px 黑描边。
- 部分弓、披风、弓光贴近相邻帧边界。W 中段、R 蓄力段尤其应逐帧检查，不要仅做机械等分裁切。
- Q 发动第 5 帧的光效范围偏大，收尾时缩减为弓附近的小光效，避免人物本体显得忽大忽小。
- R 命中特效第 3–6 帧中心仍有冰纹与雾，若叠加后遮挡目标，请清理中心或调整前后层；第 9 帧应补强消散，避免最后突然切空。
- 动作遵循参考的阶段与大致姿势，不能视为逐像素复刻原版动画。切帧后请用原计划时长预览循环、过渡和出手时刻，必要时微调。
- 全身形象比最终游戏角色大得多；紧凑头像、武器占地、地形遮挡和游戏内动画连贯性由导入后验证。

## 文件说明

- `PROMPTS_ORIGINAL.md`：用户压缩包原文，含全部提示词、帧数、计划时长及技能对应关系。
- `PROMPTS_USED.json`：实际发给桥接生成器的提示词，含修正时补充的留白及持弓约束。
- `manifest.json`：PNG 尺寸、alpha、SHA-256、预期帧数、计划时长和仅供参考的等宽切分坐标。
- `preview.html`：本地透明棋盘格预览，可直接打开；无需网络。

原包中的 Riot 模型及姿势渲染只作为本地生成参考，未加入本交付包。请继续使用原压缩包中的姿势图进行动作核对；不要将这些 Riot 渲染参考提交到仓库。
